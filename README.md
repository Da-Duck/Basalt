# 🪨 Basalt

> **Бесплатный кроссплатформенный Open Source заметочник (альтернатива Obsidian) на базе локальных Markdown-файлов с бесплатной синхронизацией «из коробки» через ваши личные облака.**

## 🎯 В чём идея проекта?

Большинство пользователей любят **Obsidian** за приватность, локальные Markdown-файлы и скорость работы. Но главная проблема — **платная синхронизация** ($4–$8 в месяц), а существующие сторонние плагины сложны в настройке или работают нестабильно на смартфонах.

**Basalt** решает эту проблему раз и навсегда:
* **100% Local-First:** Ваши заметки — это обычные `.md`-файлы на вашем диске. Никаких проприетарных форматов и привязки к сервису (Zero Vendor Lock-in).
* **Бесплатная синхронизация «из коробки»:** Подключение Яндекс Диска, Google Drive или любого WebDAV-сервера в пару кликов без подписок.
* **Единый технологический стек (90%+ общего кода):** Одинаковый быстрый и удобный интерфейс на ПК (Windows, macOS, Linux) и смартфонах (Android, iOS).

---

## 🛠️ Технологический стек

* **Ядро и UI:** TypeScript, HTML5, Modern CSS (Design Tokens, Dark/Light темы).
* **Движок редактора:** [CodeMirror 6](https://codemirror.net/) — промышленный модульный стандарт для работы с кодом и Markdown (тот же движок, что и в самом Obsidian).
* **Сборщик:** [Vite](https://vitejs.dev/).
* **Десктоп-версия (ПК):** Electron.
* **Мобильные платформы:** CapacitorJS (Android / iOS).

## 🚀 Быстрый старт для разработки

```bash
# Клонировать репозиторий
git clone https://github.com/Da-Duck/Basalt.git
cd Basalt

# Установить зависимости
npm install

# Запустить локальный сервер разработки
npm run dev
```

После запуска перейдите по адресу `http://localhost:5173`.
