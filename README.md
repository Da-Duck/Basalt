## О проекте

Basalt — это автономное приложение для ведения заметок и управления личной базой знаний (Personal Knowledge Management, PKM), созданное по принципу **Local-First**.

Приложение работает непосредственно с локальной файловой системой через браузерный File System Access API. Все ваши заметки хранятся в виде стандартных текстовых файлов `.md` на вашем компьютере. Никаких закрытых баз данных, облачной зависимости или привязки к платформе (Zero Vendor Lock-in).

Basalt объединяет производительность промышленного редактора CodeMirror 6, интерактивный рендеринг Markdown, совместимость с Obsidian (двусторонние ссылки WikiLinks) и гибкую систему визуальной организации заметок.

## Ключевые возможности

### 1. Архитектура Local-First и независимость данных
* **Прямая работа с локальным диском:** Открывайте любую папку на вашем компьютере как отдельное хранилище (Workspace / Vault).
* **Чистый формат Markdown:** Заметки сохраняются как стандартные `.md` файлы, доступные для открытия в любом стороннем редакторе (VS Code, Obsidian, Typora, Notepad).
* **Изолированные метаданные:** Настройки цветов, иконки и параметры заметок вынесены в служебный каталог `.basalt/metadata.json`. Ваши исходные Markdown-документы не загрязняются нестандартным служебным синтаксисом.
* **100% приватность:** Приложение работает полностью на стороне клиента. Отсутствуют скрытая телеметрия, аналитика и сбор пользовательских данных.

### 2. Мощный редактор на базе CodeMirror 6
* Современный модульный движок редактирования кода и разметки.
* **Меню быстрых команд по слэшу (Notion-style Slash Menu):** Нажатие символа `/` на новой строке или после пробела вызывает контекстное всплывающее меню для быстрой вставки заголовков, списков задач, врезок, таблиц, дат и блоков кода с поиском и клавиатурной навигацией.
* Подсветка синтаксиса Markdown.
* Нумерация строк, умные отступы, мягкий перенос строк.
* Полноценная поддержка истории правок: `Ctrl+Z` (Undo), `Ctrl+Shift+Z` и `Ctrl+Y` (Redo), работающая независимо от текущей раскладки клавиатуры.
* Горячая клавиша быстрого сохранения: `Ctrl+S`.

### 3. Режимы отображения и интерфейс без смещений
* **Три режима работы:**
  * **Редактор:** фокус на вводе текста без отвлекающих элементов.
  * **Разделенный экран (Split View):** синхронное отображение редактора и живого рендеринга Markdown бок о бок.
  * **Просмотр:** чистое визуальное чтение отрендеренного документа.
* **Статичный интерфейс:** Элементы переключения режимов зафиксированы по центру и не смещаются при изменении счётчика символов или статуса сохранения.

### 4. Интерактивный рендеринг Markdown
* Заголовки уровней от H1 до H6 с генерацией якорных ссылок.
* Форматирование текста: полужирный, курсив, зачеркнутый, встроенный код.
* **Информационные врезки и предупреждения (Callouts):** Поддержка блоков `> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`, `> [!IMPORTANT]`, `> [!CAUTION]` с акцентными цветными полосами и векторными значками.
* **Интерактивные списки задач (Task Lists):** Отметка чекбоксов (`- [ ]` / `- [x]`) прямо в окне просмотра мгновенно обновляет исходный Markdown-текст в редакторе и файле.
* **Блоки кода:** Отображение названия языка и кнопка быстрого копирования содержимого в буфер обмена в один клик.
* Таблицы с выравниванием по левому, правому краю или центру.
* Цитаты (Blockquotes), разделители (`---`), изображения (локальные и внешние).

### 5. Сеть связей и навигация (WikiLinks)
* **Obsidian-совместимые ссылки:** Поддержка синтаксиса `[[Название заметки]]` и псевдонимов `[[Путь/Заметка|Отображаемый текст]]`.
* **Стандартные Markdown-ссылки:** Поддержка относительных ссылок на другие файлы формата `[Текст](файл.md)`.
* **Мгновенный переход:** Клик по ссылке мгновенно открывает связанную заметку в дереве файлов.
* **Автоматическое создание заметок:** Если целевой документ по ссылке еще не существует, Basalt предложит создать его в один клик.
* Безопасное открытие внешних веб-ссылок в новой вкладке (`target="_blank"`, `rel="noopener noreferrer"`).

### 6. Облачная синхронизация (Cloud Sync)
* **Прямая интеграция с Яндекс Диском:** Быстрая и надежная синхронизация через официальный REST API (`cloud-api.yandex.net/v1/disk`) с использованием OAuth-токена. Полная поддержка CORS в браузере без необходимости промежуточных серверов или расширений.
* **Двусторонний движок синхронизации (SyncEngine):**
  * Отслеживание изменений на базе локального манифеста: выгрузка созданных файлов в облако, загрузка обновлений с других устройств и удаление удаленных файлов.
  * Синхронизация метаданных заметок (`.basalt/metadata.json`): иконки, цвета и структура сохраняются одинаковыми на всех ваших устройствах.
  * Проверка подключения и диагностика: получение сведений об аккаунте и оставшемся свободном дисковом пространстве.
* **Автоматический и ручной режимы:** Быстрая кнопка запуска синхронизации в заголовке приложения, статус-индикатор процесса в реальном времени и настраиваемая автосинхронизация при сохранении заметок.
* **Безопасность:** Учетные данные и токены сохраняются строго локально в вашем браузере. Данные передаются напрямую между вашим устройством и облаком.

### 7. Управление хранилищем и файловая структура
* **Дерево файлов:** Иерархическое отображение папок и документов с неограниченной вложенностью.
* **Организация Drag-and-Drop:** Перетаскивание заметок между папками мышью.
* **Контекстные операции:** Быстрое создание заметок и вложенных папок, переименование и удаление через контекстные меню.
* **Многопользовательские пространства (Workspaces):** Создание и быстрое переключение между несколькими независимыми каталогами-хранилищами с сохранением истории доступа.

### 8. Безопасная корзина (Trash Bin)
* Защита от случайного удаления: файлы перемещаются во внутренний каталог `.basalt/trash/`.
* Модальное окно управления корзиной: просмотр удаленных файлов, времени удаления и исходного пути.
* Восстановление документов на исходное место в дереве в один клик.
* Настраиваемый срок автоматической очистки корзины (7, 14, 30, 90 дней или бессрочное хранение).

### 9. Визуальная персонализация и темы
* **Кастомизация заметок:**
  * Назначение уникальных векторных SVG-иконок из каталога или эмодзи-бейджей.
  * Цветовая маркировка названий заметок (палитра гармоничных оттенков или произвольный выбор цвета).
* **Темы оформления:**
  * **Ochre (по умолчанию):** тёплая минималистичная тёмная палитра с охровыми минеральными акцентами.
  * **OLED Pure Black:** глубокая чёрная тема для AMOLED/OLED дисплеев с максимальным контрастом.
  * **Light:** чистая светлая тема для работы при дневном освещении.
  * Пользовательский выбор цвета акцента через встроенную палитру.

### 10. Локализация и встроенная документация
* Полная поддержка двух языков: Русский и English. Переключение интерфейса на лету без перезагрузки.
* Встроенная интерактивная справка по синтаксису Markdown с наглядными примерами.

## Технологический стек

* **Язык разработки:** TypeScript 5.x (строгая типизация)
* **Сборщик:** Vite 6.x
* **Редактор:** CodeMirror 6 (`@codemirror/view`, `@codemirror/state`, `@codemirror/language`, `@codemirror/lang-markdown`)
* **Слой хранения:** File System Access API + IndexedDB для сохранения дескрипторов сессий
* **Синхронизация:** Яндекс Диск REST API с поддержкой CORS в браузере
* **Стилизация:** Чистый модульный CSS с системой Design Tokens (CSS Custom Properties), без тяжеловесных UI-фреймворков для максимальной производительности

## Быстрый старт

### Требования

Для работы с локальной файловой системой требуется современный браузер на базе Chromium с поддержкой File System Access API:
* Google Chrome (версия 86+)
* Microsoft Edge (версия 86+)
* Brave
* Opera
* Яндекс Браузер

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Da-Duck/Basalt.git
   cd Basalt
   ```

2. Установите зависимости проекта:
   ```bash
   npm install
   ```

3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте в браузере адрес, указанный в консоли (по умолчанию `http://127.0.0.1:5173`).

### Сборка для продакшена

Для сборки оптимизированной статической версии:

```bash
npm run build
```

Собранные файлы будут размещены в каталоге `dist/`. Для их предварительного просмотра выполните:

```bash
npm run preview
```

## Горячие клавиши

| Сочетание клавиш | Действие |
| :--- | :--- |
| / | Открытие всплывающего меню быстрых блоков (Notion-style Slash Menu) |
| Ctrl + Стрелка вверх / вниз | Быстрое переключение между папками и заметками в левой панели |
| Ctrl + Enter | Открыть/закрыть выбранную папку или открыть заметку и перейти в редактор |
| Ctrl + S | Принудительное сохранение текущей заметки на диск |
| Ctrl + Z | Отмена последнего действия (Undo) |
| Ctrl + Shift + Z | Повтор отмененного действия (Redo) |
| Ctrl + Y | Альтернативный повтор действия (Redo, для Windows) |
